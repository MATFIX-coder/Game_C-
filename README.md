# ⛏️ Шахтёр: Тайны глубин

---

## 🎮 ОБЩАЯ ХАРАКТЕРИСТИКА

| Параметр | Описание |
|----------|---------|
| **Название** | Шахтёр: Тайны глубин |
| **Жанр** | Пошаговая логическая игра с элементами риска |
| **Платформа** | Windows Forms (C# .NET) |

---

## 📖 КРАТКОЕ ОПИСАНИЕ

Игрок управляет шахтёром и исследует шахту, разбитую на уровни. Цель — собрать все артефакты, избегая мин и пропастей.  
Мины дают шанс выжить через мини-игру (анаграмма), пропасти — всегда наказывают.  
После каждого уровня открывается магазин, где игрок усиливает характеристики.  
На поздних уровнях появляется ограниченная видимость, что превращает игру в тактическое исследование.

---

## ⚙️ ОСНОВНЫЕ МЕХАНИКИ

| Механика | Описание |
|----------|----------|
| **Перемещение** | Управление стрелками по сетке |
| **Подсказки** | Цифры показывают количество мин рядом |
| **Мины** | При наступлении открывается анаграмма. Ошибка → урон |
| **Пропасти** | Не видны. При наступлении: -50% HP и -10 к максимуму, возврат назад |
| **Артефакты** | Цель уровня. Дают монеты |
| **Кирка** | Тратится при перемещении и добыче |
| **Магазин** | Улучшения между уровнями |
| **Тёмные уровни** | Ограниченная видимость (радиус 1 клетка) |

## 🎯 ЦЕЛИ ИГРОКА

- Собрать все артефакты на уровне  
- Пройти 5 уровней  
- Сохранить здоровье и ресурсы  

**Поражение:**
- здоровье = 0  
- кирка сломана  

---

## 💎 РЕСУРСЫ

| Ресурс | Описание |
|--------|----------|
| ❤️ Здоровье | Уменьшается от мин и пропастей |
| 💖 Максимальное здоровье | Уменьшается от пропастей |
| ⛏ Кирка | Тратится при действиях |
| 🪙 Монеты | Получаются за артефакты |

---

## 🛒 МАГАЗИН

После каждого уровня.

| Улучшение | Эффект |
|-----------|--------|
| Здоровье | Восстановление |
| Максимальное здоровье | Увеличение лимита |
| Кирка | Восстановление прочности |

---

## 🔤 АНАГРАММЫ

При наступлении на мину открывается мини-игра.

- Правильный ответ → мина обезврежена  
- Ошибка → игрок получает урон  

---

## 🌑 ТЁМНЫЕ УРОВНИ

- Видимость ограничена радиусом **1 клетка**
- Остальная карта скрыта
- Игрок видит только ближайшее окружение
- Логика игры не меняется, только отображение

---

## 🔴 ПРОПАСТИ

- Не видны на карте  
- При приближении игрок мигает красным  
- При наступлении:
  - возврат назад  
  - -50% текущего здоровья  
  - -10 к максимальному здоровью
