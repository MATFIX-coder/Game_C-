# НЕДЕЛЯ 1: ОСНОВА И ПЕРЕМЕЩЕНИЕ

## Что нужно сделать

### 1. Создание проекта и структуры
- Создать новый проект Windows Forms
- Организовать папки для классов, форм и перечислений
- Создать перечисление типов клеток (пусто, артефакт, мина, пропасть, лестница)

### 2. Классы данных
- Создать класс игрока (здоровье, прочность кирки, монеты, координаты)
- Создать класс игры (текущий уровень, карта, массив открытых клеток)

### 3. Отображение поля
- Добавить на форму DataGridView или TableLayoutPanel
- Настроить размер ячеек (примерно 40×40 пикселей)
- Сделать так, чтобы все клетки изначально отображались как (придумать как)

### 4. Перемещение шахтёра
- Настроить KeyPreview формы для захвата нажатий клавиш
- Реализовать обработку стрелок (вверх, вниз, влево, вправо)
- Добавить проверку границ поля
- Сделать отображение шахтёра в виде иконки или символа в выбранной клетке

### Итог недели 1
- Проект запускается
- Видно игровое поле
- Шахтёр перемещается по полю с помощью стрелок
- При перемещении старая клетка очищается, новая помечается

# НЕДЕЛЯ 2: ДОБАВЛЕНИЕ АРТЕФАКТОВ

## Что нужно сделать

### 1. Генерация артефактов
- Добавить в класс Game метод генерации поля
- Размер поля: 6×6
- Разместить на поле 3 артефакта в случайных местах
- Убедиться, что артефакты не накладываются друг на друга
- Остальные клетки оставить пустыми
- Местоположение шахтёра должно быть свободным (не на артефакте)

### 2. Открытие клеток
- При наступлении шахтёра на клетку она открывается
- Если клетка содержит артефакт → отобразить (придумать)
- Если клетка пустая → отобразить (придумать)
- Клетка больше не отображается как (придумать)

### 3. Счётчик монет и артефактов
- Добавить на форму две надписи:
  - Монеты: 0
  - Артефактов собрано: 0
- При наступлении на артефакт:
  - Монеты увеличиваются на 10
  - Счётчик артефактов увеличивается на 1
  - Артефакт исчезает с поля

### 4. Завершение уровня
- Когда собраны все 3 артефакта → показать сообщение об успешном прохождении
- Игра завершается или ждёт перезапуска

### Итог недели 2
- Поле генерируется при запуске с 3 артефактами
- Шахтёр ходит и открывает клетки
- Артефакты дают монеты
- Счётчики монет и артефактов обновляются
- После сбора всех артефактов выводится сообщение
