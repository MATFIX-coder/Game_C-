## 📖 КРАТКОЕ ОПИСАНИЕ

Игрок управляет шахтёром, который спускается в глубины заброшенных шахт. Задача — собрать древние артефакты, избегая мин и пропастей. На каждом уровне игрок получает цифровые подсказки, которые помогают вычислить расположение мин. При наступлении на мину открывается мини-игра «Анаграмма» — если игрок разгадает слово, мина обезврежена. За найденные артефакты начисляются монеты, которые можно потратить на улучшение снаряжения в магазине между уровнями. С каждым новым этажом сложность возрастает: появляются пропасти (невидимые, но ощущаемые через мигание персонажа) и тёмные уровни (ограниченная видимость).

## ⚙️ ОСНОВНЫЕ МЕХАНИКИ

| Механика | Описание |
|----------|----------|
| **Пошаговое перемещение** | Управление шахтёром с помощью клавиш-стрелок по сетке |
| **Система подсказок** | На открытых безопасных клетках отображаются цифры (1-8), показывающие количество мин в соседних клетках |
| **Мины** | При наступлении открывается мини-игра «Анаграмма». Успех → мина обезврежена. Провал → потеря 1 здоровья |
| **Пропасти** | Не видны на карте. При приближении шахтёр начинает мигать красным. Наступление → -1 здоровье, возврат на предыдущую клетку |
| **Артефакты** | Главная цель сбора. Каждый даёт +10 монет |
| **Кирка** | Имеет прочность. Уменьшается при каждом шаге на неизведанную клетку. При разрушении → поражение |
| **Магазин** | Между уровнями можно купить: укрепление кирки, яблоко (восстановление здоровья), детектор (подсветка мин), сапёрный набор (автообезвреживание мины) |
| **Тёмные уровни** | Видимость ограничена радиусом 2 клетки вокруг шахтёра. Пропасти по-прежнему не видны, но мигание работает |

## 🎯 ЦЕЛИ ИГРОКА

- **Основная цель:** собрать все артефакты на каждом уровне и пройти 5 этажей
- **Дополнительная цель:** сохранить максимальное количество здоровья и прочности кирки
- **Условие поражения:** здоровье = 0 ИЛИ кирка сломана

## 🌑 ОСОБЕННОСТИ ТЁМНЫХ УРОВНЕЙ

- Видимость ограничена **радиусом 2 клетки** вокруг шахтёра
- Клетки за пределами радиуса отображаются как `???`
- **Пропасти не видны**, но мигание персонажа работает
- Цифры-подсказки видны только на открытых клетках в радиусе видимости

---

## 🔴 МЕХАНИКА ПРОПАСТЕЙ

- Пропасти **никогда не видны** на карте (даже если игрок уже на них наступал)
- Когда шахтёр находится **в соседней клетке** от пропасти (сверху, снизу, слева, справа), его клетка **начинает мигать красным**
- При наступлении на пропасть: **-1 здоровье**, возврат на предыдущую клетку
- Игрок может запоминать расположение пропастей по своему опыту
