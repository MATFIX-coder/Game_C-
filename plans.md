## 🎯 ОБЩАЯ ЦЕЛЬ ПЕРВЫХ ДВУХ НЕДЕЛЬ

Создать работающий прототип игры с базовым перемещением, генерацией поля и основными типами клеток. К концу второй недели игрок должен уметь ходить по полю, собирать артефакты и видеть изменение своих ресурсов.

---

# НЕДЕЛЯ 1: ОСНОВА И ПЕРЕМЕЩЕНИЕ

## Что нужно сделать

### 1. Создание проекта и структуры
- Создать новый проект Windows Forms
- Организовать папки для классов, форм и перечислений
- Создать перечисление типов клеток (пусто, артефакт, мина, пропасть, лестница)

### 2. Классы данных
- Создать класс игрока (здоровье, прочность кирки, монеты, координаты)
- Создать класс игры (текущий уровень, карта, массив открытых клеток)

### 3. Отображение поля
- Добавить на форму DataGridView или TableLayoutPanel
- Настроить размер ячеек (примерно 40×40 пикселей)
- Сделать так, чтобы все клетки изначально отображались как (придумать как)

### 4. Перемещение шахтёра
- Настроить KeyPreview формы для захвата нажатий клавиш
- Реализовать обработку стрелок (вверх, вниз, влево, вправо)
- Добавить проверку границ поля
- Сделать отображение шахтёра в виде иконки или символа в выбранной клетке

### Итог недели 1
- Проект запускается
- Видно игровое поле
- Шахтёр перемещается по полю с помощью стрелок
- При перемещении старая клетка очищается, новая помечается

# НЕДЕЛЯ 2: ГЕНЕРАЦИЯ ПОЛЯ И ТИПЫ КЛЕТОК

## Что нужно сделать

### 1. Генерация случайного поля
- Реализовать функцию создания поля заданного размера (начать с 6×6)
- Разместить на поле случайным образом:
  - Артефакты (3-4 штуки)
  - Мины (5-8 штук)
  - Остальные клетки оставить пустыми
- Убедиться, что объекты не накладываются друг на друга

### 2. Открытие клеток
- При наступлении шахтёра на клетку она должна "открываться"
- Отображать содержимое клетки:
  - Артефакт → показывать иконку или символ
  - Мина → показывать предупреждение
  - Пустая клетка → показывать точку или оставлять пустой

### 3. Система ресурсов
- Добавить на форму отображение:
  - Здоровья (сердечки или число)
  - Прочности кирки
  - Количества монет
  - Собранных артефактов на уровне
- При сборе артефакта увеличивать количество монет на 10
- При каждом шаге уменьшать прочность кирки на 1

### 4. Логирование действий
- Добавить область для текстового лога (ListBox или TextBox)
- Записывать туда важные события:
  - Найден артефакт
  - Уменьшение прочности кирки
  - Предупреждение о мине

### Итог недели 2
- Поле генерируется случайно при запуске
- При наступлении на артефакт игрок получает монеты
- Ресурсы отображаются и обновляются в реальном времени
- Кирка постепенно изнашивается
